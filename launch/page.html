How the build works

            
No framework and no runtime: all of it happens at build time.

          

          
    
            
  1. Reads config.json and checks it. A missing url stops the build and names the row.
    2. 
            
  2. Picks an icon for each link from icons/icons.json, copying in new brands from Simple Icons.
    3. 
            
  3. Makes each brand colour readable on black and assigns the keyboard keys.
    4. 
            
  4. Renders the bio and footer through a small inline-Markdown pass.
    5. 
            
  5. Writes the HTML, CSS and icons into dist/index.html and draws dist/social-card.png.
